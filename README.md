# Markdown2Word

一个基于 Python + Tkinter 的小工具，用于把 Markdown 文本快速转换为 Word 文档（`.docx`）。

项目提供了简单的图形界面，适合将ai的markdown格式的回答整理为word笔记、将ai翻译的论文转化为word文档等场景。当前实现重点放在中文文档排版、公式转换、图片与超链接处理，以及更符合中文写作习惯的段落输出效果。

**可直接双击./markdown2word 文件夹下的 exe 程序运行本程序，简单快捷**

## 目前支持

- 图形界面直接粘贴 Markdown 并导出 Word
- 标题、普通段落、粗体、斜体、下划线、代码块
- 表格、图片、超链接
- 普通 Markdown 链接指向可嵌入的图片时会自动插图，支持本地路径和无扩展名的网络图片；网页或无法嵌入的目标保留为超链接
- 兼容复制链接标题中的 `\[...\]` 和地址中的 `\&`。网络图片返回 HTTP 404 时，响应中可读取的图片数据仍可嵌入
- 正文和链接文字中的邮箱转义 `\@` 自动显示为 `@`，代码中的原样文本及显式转义的反斜杠予以保留
- 行内公式与独占一行公式
  - 行内支持 `$...$`、`\(...\)` 和双反斜杠写法 `\\(...\\)`
  - 块公式支持 `$$...$$`、`\[...\]` 和双反斜杠写法 `\\[...\\]`
  - 双反斜杠边界中的转义 LaTeX 命令与花括号会自动兼容，保留标准矩阵、对齐和分段公式中的 `\\` 换行；代码块和行内代码不参与公式转换
  - 支持方框内的分段公式：大括号自动拉伸，单列分段内容左对齐；兼容混合转义的 `\\\\[4pt]` 换行，不产生多余空行
  - 兼容多层转义的公式边界，以及复制文本中的下标、星号转义；保留公式文字命令中的字面下划线和代码内容
  - 复制公式中的 `\_n`、`\_0`、`\_\alpha` 等无花括号下标也会恢复为真正的数学下标
  - `\binom`、`\dbinom`、`\tbinom` 的括号会随组合数的上下两项自动拉伸，也支持嵌套组合数
  - `\tilde`、`\widetilde`、`\hat`、`\widehat` 使用 Word 原生数学重音，避免符号与变量上下分离
  - 求和项支持以负号、正号等符号开头，保留括号内的加减运算，避免出现空求和占位框
  - `\operatorname{SmoothL1}` 等带数字的函数名保持正体显示，并可作为完整求和项；兼容星号及 `withlimits` 写法
  - 矩阵后的尺寸下标、转置上标及上下标组合均作用于整个矩阵，保留完整的可伸缩括号，支持嵌套矩阵
  - 兼容矩阵复制文本中普通变量、数字前多出的换行反斜杠，保留换行后的合法 LaTeX 命令、文本内容及原生矩阵空行
  - 兼容范数双竖线在括号命令后的额外转义，保留可伸缩的双竖线和整体下标，不改动矩阵换行或文字中的字面反斜杠
  - 行内求和按实际写出的上下限显示侧边上下标，省去缺失一侧的空框。兼容复制的行内范数中的双竖线转义
  - 短变量的 `\underbrace` 下花括号适当加宽，单位或说明文字居中对齐
  - 独立公式的分子、分母中可用 `\displaystyle` 将求和上下限置于求和号正上方和正下方，保留完整求和项
- 独占一行的公式会单独成段并居中显示且不首行缩进
- 块公式居中显示
- 带编号的块公式使用 Word 原生显示公式编号结构，编号右对齐，求和等大运算符的上下限保持在符号上下方；行内公式及显式 `\nolimits` 保留侧边上下标
- 正文可在 GUI 中选择首行缩进 2 字符或顶格
- 显式 HTML 对齐优先于正文缩进选项：独立的 `<div align="center">` 内段落无缩进居中，`<div align="left">` 内段落无缩进且保持两端对齐；支持转义的 `\<div>`、内部 Markdown 和嵌套对齐，容器外正文继续使用全局设置
- 一级标题居中显示
- 单独一行的“摘要”居中显示
- 独占一行的图片居中显示且不首行缩进
- 正文中连续独占一段的图片自动紧凑排版，每行两至三张。三张图中首图接近方形且后两张较宽时，排成左侧主图、右侧上下两图。图片保留原比例，正文或题注会分隔图片组
- 识别连续的论文缩略图、单独加粗的标题和作者等信息列表，导出为左图右文的论文卡片
- 导出时过滤可识别的网页 favicon，并清除紧跟的「来源名称+数量」行
- 题注识别与居中
  - 例如 `表3：XXX`、`图2：XXX`、`Table 1: XXX`、`表1 XXX`、`表1. XXX`
- 有序列表按原文重新从 `1.` 开始
- 转换完成后自动尝试打开生成的 Word 文档（Windows / macOS / Linux 图形界面）
- SVG 图片会通过 `cairosvg` 自动转换为 PNG 后插入；如果转换失败，可以先手动把 SVG 转成 PNG/JPG
- 如果希望转换完成后自动打开文档
  - macOS 需要系统自带 `open`
  - Linux 需要桌面环境和 `xdg-open`
- setting.json中的
  - output_dir（输出目录），默认输出目录优先取用户的 Downloads，如果没有就尝试 下载，再不行就退回到用户主目录
  - asset_root（资源根目录），默认为当前工作目录，也就是你从哪里启动程序，默认资源根目录就指向哪里
  - title_chars（导出文件名截取的标题长度），默认是 12
  - body_first_line_indent（正文首行是否缩进），默认是 True
  - markdown_word_wrap（Markdown 输入框是否自动换行），默认是 False
- GUI 顶部可填写保存文件名，可填 `xxx` 或 `xxx.docx`；不填则继续按 `title_chars` 自动生成
- 遇到同名文件时自动保存为 `xxx(1).docx`、`xxx(2).docx`
- `Ctrl+S` 可直接运行并生成 Word
- Markdown 输入框支持自动换行开关，关闭后显示横向滚动条
- Markdown 输入框支持 `Ctrl+Z` 撤销、`Ctrl+Y` 重做
- `Ctrl+F` 打开查找栏，不区分大小写并高亮匹配；查找栏中按 `Enter` / `Shift+Enter` 跳到下一个 / 上一个，首尾循环，`Esc` 关闭并返回输入框

## 适用场景

- 将 Markdown 笔记快速整理成 Word 文档
- 将ai帮忙完成的课程作业、实验报告、论文翻译稿从 Markdown 导出为 `.docx`
- 将ai回答的有用知识从 Markdown 导出为 `.docx`，方便整理笔记
- 将包含公式、图片、表格的中文技术文档转换为可继续编辑的 Word 文件

## 环境要求



### 双击运行

- 带图形界面的 Windows、macOS 或 Linux 环境
- 电脑安装 Microsoft Office 并设为`.docx`的默认打开软件（wps打开的话公式阅读正常但可能复制粘贴格式会出问题）

### 源码运行
- Python 3.10 及以上版本
- 推荐使用 conda 环境运行，Tkinter、Cairo 等底层依赖统一由 conda 管理
- 电脑安装 Microsoft Office 并设为`.docx`的默认打开软件（wps打开的话公式阅读正常但可能复制粘贴格式会出问题）


## 运行方式

### 双击 markdown2word.exe 程序运行

./markdown2word 文件夹下有已经打包好的 exe 程序，直接双击运行已经打包好的程序，无需配置python环境。这种方式最简单直接，同时可鼠标右键创建快捷方式放到桌面供以后使用，方便快捷。

### 使用 base 环境（方便简单项目管理）

如果只是自己电脑上长期使用，可以直接在 conda 的 `base` 环境里安装依赖并运行：

```bash
conda activate base
conda install -c conda-forge tk cairosvg cairo
pip install -r requirements.txt
python markdown2word.py
```

这种方式步骤更少，适合简单项目的统筹 base 管理，但会把本项目依赖安装到 `base` 环境中。如果希望环境更干净，建议使用下面的专用环境方式。

### 新建环境（环境更干净）

安装 Anaconda 或 Miniconda 后，在项目目录打开终端，执行：

```bash
conda create -n markdown2word python=3.10 pip tk cairosvg cairo -c conda-forge
conda activate markdown2word
pip install -r requirements.txt
python markdown2word.py
```

## 打包指令

### Windows exe

exe程序已经打包并放在 markdown2word 文件夹下

```bash
pyinstaller --noconfirm --clean --windowed --onefile --icon data/app_icon.ico --add-data "mml2omml.xsl;." --collect-data latex2mathml markdown2word.py
```

### macOS / Linux

注意 `--add-data` 的分隔符要改成 `:`，且打包过程需自己运行下述指令完成

```bash
pyinstaller --noconfirm --clean --windowed --onefile --add-data "mml2omml.xsl:." --collect-data latex2mathml markdown2word.py
```
